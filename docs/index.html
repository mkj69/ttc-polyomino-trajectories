    READING THIS ARCHIVE

    Evidence, with its limits.

    Three protocols

    Solo: one agent. Team 3: three agents using official antiherding, sharing the graded solution file. Isolated 3: private working solutions, with a lock-guarded promotion of strictly better candidates.

    Measured vs. inferred

    Rewards come from final trial results. Submission times and scores come from judge logs. Tool calls come from completed event records. Shared-log activity is classified from command text; no causal knowledge-transfer claim is made.

    A readable projection

    Harbor shows a timestamp-merged ATIF projection with agent and session labels. Completed messages, reasoning, tools, results, and errors are retained. Streaming deltas stay in the sanitized source logs. Events can interleave; tool results appear with their originating call.

    Public, static, sanitized

    No live agent or API backend. Network authorities and credentials are redacted; binaries are excluded. Code is MIT, data CC BY 4.0, and Harbor’s bundled viewer is Apache 2.0. Third-party material retains its original terms.
